1. สถานะและการใช้งานเอกสาร
• เอกสารฉบับนี้เป็นมาตรฐานกลางของ Student Health Center Design System v1.1 สำหรับทีมออกแบบและทีมพัฒนา
• ทีมพัฒนาต้องยึดสี ฟอนต์ ระยะห่าง ไอคอน ปุ่ม ฟอร์ม ตาราง การ์ด และกฎการออกแบบตามเอกสารนี้

• ทุกหน้าต้องรองรับทั้งหน้าจอคอมพิวเตอร์และหน้าจอมือถือ

30. Single Theme Policy
Version 1.1: ไม่เปิดใช้งาน
ไม่พัฒนา Theme toggle และไม่เตรียม Token ชุดที่สอง เพื่อลดความซับซ้อนและความเสี่ยงในการดูแลโค้ด
31. Design Rule — กฎสูงสุด
1. ข้อมูลสำคัญต้องเห็นก่อนความสวยงาม
2. ทุกหน้าต้องใช้ Component กลางเท่านั้น
3. ห้ามสร้างสีใหม่หรือขนาดใหม่โดยไม่มีการอนุมัติ
4. ทุกหน้าต้อง Responsive ทั้ง Desktop และ Mobile
5. ทุกองค์ประกอบต้องใช้ Design Token จากระบบกลาง
6. การเพิ่ม Component ใหม่ ต้องผ่านการอัปเดต Design System ก่อนนำไปใช้ในโค้ด
7. เอกสารฉบับนี้เป็นมาตรฐานอ้างอิงหลักสำหรับทีมพัฒนาใน Version 1.1

34. Single Theme Engineering Contract
• ประกาศ Token เพียงชุดเดียวใน :root และห้ามมี [data-theme], .dark หรือ prefers-color-scheme branch
• ห้าม Hardcode สีในหน้า Module; ใช้ CSS Variables กลางเท่านั้น
• Primary Action ใช้ข้อความสีขาว ส่วน Warning ใช้พื้น #FEF3C7 กับข้อความ #92400E
• Sheet Header ใช้ #0B1F3A กับข้อความสีขาว เพื่อให้ชื่อฐานข้อมูลตรงกับ Visual Contract
• Icon Set ใช้ 24 × 24 px, safe area 20 × 20 px, stroke 2 px, round cap/join และ lower_snake_case.svg
• ภาพคู่มือ Icon Set ที่แสดงลำดับ Drug เป็น 55 ให้แก้ label เป็น 05 ในไฟล์ภาพต้นฉบับรอบถัดไป; ชื่อไฟล์ drug.svg ถูกต้อง

36. Approval and Change Control
Student Health Center Design System v1.1 มีสถานะ APPROVED & LOCKED และแทนที่ v1.0 เฉพาะ Color Role, Single Theme Policy และ Engineering Contract ส่วน Grid, Typography, Spacing, Component และ Responsive Rule อื่นยังคงใช้ต่อ
การเพิ่ม Theme, เปลี่ยน Token, เปลี่ยน Icon construction หรือสร้าง Component ใหม่ต้องออก Change Request และ Regression Test ก่อนนำไปใช้ในโค้ด
